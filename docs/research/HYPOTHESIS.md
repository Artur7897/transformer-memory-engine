# TME Research Hypothesis

## Primary hypothesis

An AI entity can preserve operational continuity across replacement of its underlying language model when persistent memory and state are maintained outside the model and selectively supplied through a dedicated memory-attention architecture.

## Strong test

1. An entity operates for an extended period using Model A.
2. It accumulates persistent state and memory.
3. Model A is removed.
4. Model B is introduced without access to Model A's hidden state or weights.
5. The entity receives only its external TME state plus its defined identity/policy context.
6. Continuity is evaluated before and after replacement.

A successful experiment requires measurable preservation of relevant knowledge, commitments, relationships, task state and behavioural constraints without simply replaying the complete historical conversation.
